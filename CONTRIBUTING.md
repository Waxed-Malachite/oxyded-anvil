# Oxyded Anvil - Contributing

When contributing to Oxyded Anvil, please commit following the [Conventional Commits v1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) specification and [Conventional Branch v1.1.0](https://conventionalbranch.org/#specification) specification but with your GitHub username between type and description (e.g. feat/kitsuvm/example-feature).

It's strictly forbidden to commit to the main branch. All contributions must be made through branches and pull requests. Please make sure to create a new branch for your changes and submit a pull request for review and it's needed to be approved by [SpaceFox](https://github.com/spacefox1) and [KitsuVM](https://github.com/kitsuvm) before merging.

Please do only one work per branch/pull request. If you want to work on multiple features, please create a new branch for each feature or bug fix. This will help keep the project organized and make it easier to review your changes.
